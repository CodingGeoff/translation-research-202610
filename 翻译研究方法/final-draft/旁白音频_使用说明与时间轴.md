## 四、怎么重新生成音频

1. 用一段约 15 秒的样音先试听并注册声音（中英各一套）。
2. 按 1250 字符上限在**句子边界**切分脚本（段间空行保留，停顿更自然）。
3. 逐段合成，再用 ffmpeg 顺序拼接：
   ```bash
   ffmpeg -f concat -safe 0 -i list.txt -c copy 完整版.mp3
   ```
4. 需要压缩/放宽时长时只改变速，不改音高：
   ```bash
   ffmpeg -i 完整版.mp3 -filter:a "atempo=0.85" -ac 1 -b:a 48k 完整版_课堂节奏.mp3
   ```
